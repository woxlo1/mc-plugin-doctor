# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. If GitHub's
private vulnerability reporting is enabled for this repository, use the
repository's **Report a vulnerability** flow. Otherwise, contact the repository
maintainers privately through an established channel and include reproduction
details and impact. Do not include real credentials or other secrets in a
report.

## Scope

The project is in pre-development. No plugin analysis functionality is available
yet. Security review of analysis behavior will be added as those features are
implemented.
